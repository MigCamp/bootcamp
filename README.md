Prueba - Obtención y preparación de datos
Descripción del proyecto
Este proyecto corresponde a una de las evaluaciones desarrolladas durante el curso de Fundamentos de análisis de datos.
El objetivo principal fue aplicar técnicas de obtención, limpieza y preparación de datos para dejar un dataset listo
para su posterior análisis, abordando un problema real de calidad e inconsistencia en los datos.

Objetivos
Obtener datos desde una fuente definida (archivo/dataset de origen).

Identificar valores nulos, duplicados e inconsistencias en el dataset.

Aplicar técnicas de limpieza y transformación de datos.

Dejar el dataset preparado y validado para su uso en análisis posteriores.

Tecnologías utilizadas
Python 3
Pandas
NumPy
Matplotlib
etc.

Mejoras aplicadas tras la retroalimentación docente
Se documentó cada paso del proceso de limpieza con comentarios explicativos en el código.

Se justificaron las decisiones tomadas al tratar valores nulos y duplicados.

Se depuró el código eliminando líneas innecesarias y mejorando la legibilidad.

Se optimizó la presentación de resultados con mensajes más claros.

Cómo ejecutar este proyecto
Clona este repositorio o descarga el archivo .py.


Instala las dependencias necesarias:
pip install pandas

Ejecuta el script:
python "Prueba - Obtención y preparación de datos.py"


Resultado
El script entrega como salida un dataset limpio y estructurado, listo para ser utilizado en etapas posteriores de análisis
estadístico o visualización de datos.
